# Dokumentationsarchiv

Dieser Ordner enthält **historische** Recherche-, Konzept- und Planungsstände.

Die Dateien bleiben erhalten, damit frühere Entscheidungen und Recherchen nachvollziehbar sind. Sie sind jedoch **keine aktuellen Arbeitsanweisungen**.

Für neue Arbeiten gelten ausschliesslich:

- `AGENTS.md`
- `README.md`
- `docs/ARBEITSPLAN_AKTUELL.md`
- `docs/PROJECT_CONTEXT.md`
- aktive Spezifikationen unter `docs/`, aktuell insbesondere `docs/ANFORDERUNGEN_TAGESPLAN.md`

Wenn ein Archivdokument einer aktiven Datei oder dem aktuellen Quellcode widerspricht, ist der Archivstand als überholt zu behandeln.

Datumspräfixe wurden nur dort verwendet, wo der historische Stand im Dokument oder Dateinamen eindeutig belegt war. Undatierte ältere Konzepte werden nicht künstlich mit einem exakten Datum versehen.
